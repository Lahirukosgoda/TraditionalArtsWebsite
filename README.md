# Traditional Arts Today

A modern, responsive website built to showcase traditional artists, their works, and the stories behind their crafts. 

## Features
- **Modern Minimalist UI**: Clean layout built with HTML, CSS (flexbox & masonry grid layout) and custom fonts (Montserrat).
- **Responsive Card Slider**: Interactive homepage carousel powered by Swiper.js.
- **Global Navigation & Footer**: Unified layout mapping across all internal pages.
- **Dynamic Artist Directory**: A beautiful, asymmetric Pinterest-style masonry grid to showcase varying aspect ratios of artworks effortlessly.

## Structure
- `/css` - Contains modular stylesheets (`style.css`, `navbar.css`, `footer.css`, etc.)
- `/js` - Contains scripts initializing interactive elements.
- `/images` - Image assets for artist profiles, artworks, and UI elements.
- `index.html`, `artist.html`, `about.html`, etc. - Standard HTML pages mapping out the main flow of the site.

## Setup
Simply clone or download this repository, and open `index.html` in your web browser. No local web server or build pipeline is required as it runs purely on static frontend technologies.
